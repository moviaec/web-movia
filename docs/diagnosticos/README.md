# docs/diagnosticos/

Auditorías y fotos del estado del proyecto en una fecha concreta: entorno, dependencias, configuración, huecos detectados.

Un diagnóstico **no se corrige ni se reescribe** cuando el proyecto cambia: se marca como superado y se escribe uno nuevo. Lo que se decidió a partir de él va en `../decisiones/`, y lo que se hizo, en `../cambios/`.
