# docs/decisiones/

Decisiones técnicas con su contexto, las alternativas descartadas y sus consecuencias (ADR ligeros). Una por archivo, para poder citarla desde el código y desde otros documentos.

No va aquí el paso a paso de la ejecución (eso es `../cambios/`) ni las convenciones obligatorias del proyecto, que viven en `.claude/CLAUDE.md` y `.claude/RULES.md`.
