# docs/cambios/

Informes de lo que se hizo y cómo se verificó: migraciones, refactors, actualizaciones de dependencias. Llevan diffs, salida literal de los comandos y qué rompió por el camino.

No va aquí el porqué de una decisión técnica (eso es `../decisiones/`) ni el estado general del proyecto (eso es `../diagnosticos/`).
